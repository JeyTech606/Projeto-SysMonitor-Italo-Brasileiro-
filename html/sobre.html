Sobre o SysMonitor

O SysMonitor é um sistema de monitoramento de desempenho desenvolvido em linguagem C, que lê dados do Gerenciador de Tarefas do Windows em tempo real e os exibe em um dashboard web moderno, com visual inspirado em painéis de bolsa de valores.

ODS 9

Inovação e Infraestrutura

O projeto se alinha ao Objetivo de Desenvolvimento Sustentável nº 9 da ONU, que propõe construir infraestruturas resilientes, promover a industrialização inclusiva e sustentável, e fomentar a inovação. O SysMonitor democratiza o acesso ao monitoramento de sistemas, oferecendo uma ferramenta gratuita, leve e de alto desempenho para estudantes e profissionais de TI.

Nossa Equipe

CL
Clovis
Página Home & Módulo CPU
Responsável pela página inicial do site e pelo módulo C de coleta de dados de CPU e processos via API PDH do Windows.
IS
Isaque
Página Sobre & Módulo RAM
Responsável pela página Sobre e pelo módulo C de leitura de memória RAM usando GlobalMemoryStatusEx do Windows.
JF
Jefferson
Dashboard Web & Integração JSON
Responsável pelo dashboard e pela integração entre o programa C e a interface web via arquivo JSON atualizado em tempo real.
VT
Vitor
Página Download & Módulo Disco/Rede
Responsável pela página de download e pelo módulo C de coleta de dados de disco e rede via APIs WMI e GetIfTable do Windows.
