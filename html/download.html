Download & Documentação

Siga as instruções abaixo para compilar e executar o SysMonitor no seu Windows. Requisitos: Windows 10/11 (64 bits), GCC/MinGW-w64 e um navegador moderno.

Requisitos do Sistema

🖥
Sistema Operacional
Windows 10 ou 11 (64 bits)
🧠
Memória RAM
Mínimo 4 GB
⚙️
Compilador
GCC via MinGW-w64
🌐
Navegador
Chrome, Firefox ou Edge

Como Instalar e Executar

1
Instale o MinGW-w64
Baixe e instale o MinGW-w64 em MSYS2. Certifique-se de adicionar o caminho do GCC à variável de ambiente PATH do Windows.
2
Compile o programa C
Abra o terminal (MSYS2 MinGW-w64) na pasta do projeto e execute: 
gcc backend/sysmonitor_api.c -o sysmonitor.exe -lws2_32 -lpdh -liphlpapi -lpsapi -lntdll -O2
3
Execute o programa
Execute o arquivo gerado. Ele irá coletar dados do sistema e gerar o arquivo sysdata.json na mesma pasta. 
.\sysmonitor.exe
4
Abra o Dashboard
Abra o arquivo html/index.html no seu navegador. O dashboard irá ler o sysdata.json automaticamente e atualizar a cada 2 segundos.

APIs do Windows Utilizadas

API Biblioteca Uso no Projeto
PDH (Performance Data Helper) pdh.lib Coleta uso de CPU por núcleo
PSAPI psapi.lib Lista processos e uso de memória por processo
GlobalMemoryStatusEx kernel32 Lê total e uso de memória RAM
GetIfTable iphlpapi.lib Monitora tráfego de rede (bytes enviados/recebidos)
GetDiskFreeSpaceEx kernel32 Lê uso de disco (livre/total)
